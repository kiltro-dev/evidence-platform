# Competitive Readiness Report — Operation First Place (2026-11-01)

## 1. Executive assessment

Evidence Atlas v0.2.0 was, at the time of writing (Operation First
Place), the best-crafted small idea in the room: real deterministic
verification, honest refusal states, 185 tests, 24/24 eval. (Historical
assessment preserved; see the v0.4.0 addendum at the end.)
It loses as-is to any competent team with deeper Meta-model use or a more
memorable demo. The winning move is NOT breadth (more connectors) but
**methodological depth + adversarial model use + refusal-centered demo**:
become "the stat-checker that refuses to lie," with Muse Spark doing
falsification work heuristics cannot, and every verdict carrying
precision-aware, uncertainty-explicit receipts.

## 2. Rubric (verified, Team A)

Impact 30% ("real-world potential, who benefits, could become something
people use, fits a problem statement") / Meta Tooling 25% ("beyond a
basic integration… unexpected capabilities") / Demo 25% ("working,
impressive… holds up live… quality of the demo video") / Tech Depth 20%
("sound and thoughtfully refined… real craft"). Indie: "creativity,
technical ambition, and whether it works." Deadline Nov 4 9PM ET.
Secondhand-but-corroborated: 3-min video is the primary artifact, public

## 4. Strategy: "The stat-checker that refuses to lie"

One bet, three pillars: (1) **Precision-aware verification** — claimed
digits checked against retrieved values with absolute materiality and
methodological uncertainties; the GDP flagship becomes the honest
`partially_supported` + flags case. (2) **Adversarial Muse Spark** — a
falsification pass that attacks each draft verdict through a
schema-constrained, code-validated, advisory-only contract, plus abstract-level
science stance; the model earns its 25%. (3) **Receipt + re-run demo** —
exportable methods receipt and live determinism proof; refusal (⊘) as
the memorable beat.

## 5. Roadmap (Phase 2 waves)

- M1 methodology core: precision rule + materiality + methodological
  codes + compound cap + summary-strength validation (+eval flips applied
  by lead). Owner files: compare/verify-quant/synthesize/extract/types.
- M2 falsification pass: new `pipeline/falsify.py`, attacks as native
  comparisons/uncertainties (zero type changes); lead wires run.py stage.
- M3 science abstracts: OpenAlex abstract fetch + new `pipeline/science.py`
  (additive stance over abstracts); lead wires imports.
- M4 infra: `reasoning_effort` (probe-first) + usage accounting, parallel
  retrieval module, model-name cache key. Owns meta.py/app.py/new module.
- M5 UX: checks bar, ChatGPT-vs-Atlas strip, severity rail, method panel,
  supported-indicator list, re-run + export receipt, copy recalibration.
  Owns web/index.html only.
- M6 eval: additive cases (precision pair, boundary synthetics 1.9/2.1),
  paraphrase experiment (E1), abstention probe (E2); never weakens pinned
  stances. Owns eval/ + scripts/ additions.
- Lead integration: run.py wiring, eval flip updates, full+degraded+live
  verification, docs sync, demo script rewrite, red-team re-review,
  milestone commit + push.

## 6. Must NOT build

Search Grounding integration, second models, vision models, evidence
graphs with physics, monitoring/scheduling, science reliability scores,
tolerance per-indicator floors (cut: precision rule covers it), new
half-done connectors, charts implying unverified verification, accuracy%
headlines (reframe as pinned regressions).

# Operation Find the Breakthrough — addendum (2026-11-01, v0.4.0)

Eight research agents + independent red team killed the fact-checker
skin (no buyers, ban-adjacent, ambition deficit) and the proposal-audit
(occupied by an incumbent GA launch), ad-substantiation (misleading
demo), legal, GRC, newsroom, and live-debate directions. The bet:
**ShipCheck** — the sidecar that checks every stat AI ships
(post-hoc numeric-claim verification API + defensible receipts).
Full rationale: [BREAKTHROUGH_DECISION.md](BREAKTHROUGH_DECISION.md).

## Updated scorecard (v0.3.0 shipped → v0.4.0)

| Dimension | v0.3.0 | v0.4.0 | What changed |
|---|---|---|---|
| Impact 30% | 7 | 8 | Named beneficiary (AI engineers) + measurable ROI story (escape rate, verification hours); batch UX proves the workflow, not a slide |
| Meta Tooling 25% | 8 | 9 | Strict `json_schema` decoding everywhere + Responses `web_search` adversarial layer + claim-splitter; model load-bearing in up to 6 calls (batch path), code still judges |
| Demo 25% | 8 | 9 | 1-1-1 batch (caught hallucination + refused credit + confirmed) + "tried to disprove itself live" beat; refusal + re-run retained |
| Tech Depth 20% | 9 | 9 | EVS hardening (pin-conformance + Wilson CIs, independent recompute, 47-cell decision table, partial-coverage fix); residuals disclosed, not hidden |

Honest ceiling: narrow catalog (WB-16/~50 countries, abstracts-only
science) caps Impact — most real AI claims land `unverifiable`, which
the demo discloses rather than hides. Speed/distribution belong to
funded incumbents; the defensible artifact is the inspectable
receipt. No win promised; this is the highest real-value, most
winnable build found.
