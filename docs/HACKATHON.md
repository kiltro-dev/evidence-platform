## Key facts

- Virtual, worldwide; up to 20,000 participants, rolling admission, 18+.
- One track per project: **Indie** (≤4 people; judged on creativity,
  technical ambition, working demo) or Startup.
- Build with Meta AI products (Muse Spark, Glimmer, SAM 3, …) + $150
  Meta Model API credits (10-day window). No quantitative minimum-use
  threshold found; weight sits in the 25% tooling criterion.
- Submission: working demo + demo video via the portal.
- **Deadline: Nov 4, 9:00 PM ET** (= Nov 5, 02:00 UTC; EST in effect).
  Judging Nov 4–8; winners announced live Nov 9.
- Criteria: Impact 30% / Use of Meta AI Tooling 25% / Demo 25% /
  Technical Depth & Execution 20%. Organizer judging panel, binding.
- Prizes: Indie $400k (150/100/75/50/25k), Startup $550k, ~$50k bonus
  pool (~Nov 10). Payment <30 days post-verification.
- IP stays with the participant, but organizers receive a perpetual,
  irrevocable, worldwide, royalty-free license; **no confidentiality**;
  recording/publicity consent; California law.
