One long-context Muse call over the FULL keynote transcript proposes
speaker self-contradiction pairs; deterministic code verifies every
pair before any `speaker.contradiction` event is published. The model
proposes; code disposes. Zero verified pairs → honest empty report,
never invented.

## Check (`run_longctx`)

Input: full transcript as parsed SRT segments `{t_sec, end_sec, text}`
plus the claims registry (context for the model only). One model call
(reasoning `low`, strict `json_schema` `m7_longctx`) proposes ≤6 pairs
`{quote_a, t_a, quote_b, t_b, entity, indicator, why}`. Code then
verifies each pair:

- **V1 literal**: both quotes exist verbatim in the transcript
  (normalized: quotes unified, case folded, whitespace collapsed).
- **V2 time match**: claimed `t_a`/`t_b` fall within tolerance of the
  segments where the quotes were actually found.
- **V3 separation**: the two ACTUAL segment starts differ by >30s.
- **V4 same entity+indicator**: the entity is a literal substring of
  both quotes; the indicator matches both quotes directly or via a
  documented EN/ES synonym group (e.g. population↔people).
- **V5 collision**: numbers are RE-extracted from both quotes with
  `src/atlas/core/units` and must share compatible (known-on-both-sides)
  units with relative difference >2% — or the pair must be an
  EXPLICIT affirmation-vs-negation clash (negation cue in exactly one
  quote + shared number token or both numberless).

Only verified pairs become `speaker.contradiction{quote_a, t_a,
quote_b, t_b, entity, indicator, why, clash, value_a, value_b, unit,
rel_diff}` bus events. Rejections carry machine-readable reasons
(`quote_not_literal`, `time_mismatch`, `same_window`,
`entity_mismatch`, `indicator_mismatch`, `no_collision`, …). One
malformed-reply retry (M2b rule); model failure → empty report with a
note, never an exception, never invented pairs.

## Findings / unresolved

1. **Reasoning floor**: the first live call truncated into empty
   content at `max_tokens=1500` with reasoning `low`
   (`finish_reason=length` — same probe-verified class as vista/
   falsify). M7 floor is now 4000; that failure also exposed that the
   error path dropped usage/cost, now fixed.
2. **Planted same-block contradictions are out of scope by design**:
   `truth.json` F14 says explicitly "contradicts T16 in this same
   talk" (8 billion in 2020 vs Nov 2022), but both sit in ONE SRT
   block (slide 7) → `same_window` discards them, as it does T7/F4,
   T11/F7, T12/F8 and T15/F10. The >30s rule only admits cross-slide
   pairs (T2/F3 here). A same-block contradiction check would be a
   separate rule, not M7.
3. **Bare-year pairs can never collide numerically**: `units_compatible`
   requires known units on both sides, so year-vs-year (2022 vs 2020)
   is not a V5 numeric collision — deliberate (years are not measures
   of the indicator), noted for future temporal-contradiction work.
4. **Pronoun references fail V4**: the real F5 doubling claim ("One
   year later it had doubled") cannot verify because "it" is not a
   literal entity. Coreference resolution would widen recall at the
   cost of the literalness guarantee; M7 keeps the guarantee.
5. **Proposal count varies run to run** (3 vs 2) but the verified set
   was identical; verification — not the model — is the source of
   truth, which is exactly the M7 contract.
