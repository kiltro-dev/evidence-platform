# M5 — Escéptico + Editor + Paquete Atlas Live

Adversarial re-verification of `supported` verdicts, bilingual verdict
cards with citation confinement, and a self-verifying evidence bundle
(ZIP + offline re-execution). All model calls use reasoning `minimal`
under strict `json_schema`; every model output is validated by code.

## Skeptic (`run_attack`)

Per `supported` verdict only (anything else → advisory note, zero model
calls): 1 structured call proposes ≤2 counter-queries → grounding
`web_search` → responsible `fetch_url` (robots, 2 MB cap, paywall
refusals — the M2b contract) → 1 structured extract call per fetched
doc for a contradicting verbatim quote → candidate package via the M2b
`build_package` (verbatim `find` + offsets by code).

Publication rule (both gates on the EXACT published dict):

- **GATE A**: `EvidencePackage.from_dict` accepts it.
- **GATE B**: the EXISTING verifier (`verify_claim`) finds it usable —
  quote literal + hash match — with outcome `contradict`.

Only then `skeptic.challenge{claim_id, package, counter_query,
rationale, verdict_detail, …}`. Anything else — invented quote,
fetch/search failure, model abstention/skip, usable-but-supporting
candidate — degrades to advisory `skeptic.note{note, queries,
docs_fetched, extracts, …}`. Corroborating evidence is reported as
"attack corroborated the verdict", never as a challenge. Bounded by
construction (≤1+2 fetches, ≤3 model calls); one malformed-reply retry
(M2b rule); never raises on model/network failure.

## Editor (`Editor.emit_card`)

Prompt carries ONLY the verified `package_ids` from the verdict event
(+ their quotes/URLs as context). Code confines the draft: every
citation must be ∈ that set, else the draft is discarded and a
deterministic fallback card (per-verdict ES/EN templates) is published.
Missing model / malformed reply → same fallback. Cards always carry
both languages + `fallback` flag.

Corrections: the editor remembers per-claim `{card_id, package_ids,
verdict}`. A repeated verdict with a NEW package (or a changed verdict)
emits `card.correction{correction_of, new_packages}`; otherwise
`card.published`. `card_id` = `card-{claim_id}-{n}`.

## Bundle (`export_bundle` + `verify_bundle.py`)

ZIP: `run.jsonl` (verbatim), `snapshots/`, `packages.json`,
`claims.json`, `truth_ref.json?`, `verify_bundle.py` (verbatim copy),
`README.txt`, `manifest.json` (sha256 per file). Export gates: every
package passes `from_dict`, every snapshot resolves and re-hashes to
the package sha, `run.jsonl` is line-JSON.

`claims.json` (claim inputs + recorded verdicts) is an addition to the
brief's file list: re-running the verifier needs claim
value/unit/raw/year, which `run.jsonl` verdicts do not carry.

`verify_bundle.py` re-executes offline (no network, no model): re-hash
all files → re-validate package dicts → re-grep literal quotes →
re-run the verifier per claim → compare against BOTH `claims.json`
and the latest `claim.verdict` in `run.jsonl` → PASS/FAIL per claim,
exit 0 iff all pass. Dual engine: `live` = the REAL
`live.verifier.check` (needs the repo); `stdlib` = a vendored
stdlib-only mirror of `src/atlas/core` + `check.py` (always available,
so a bundle verifies without the repo); `auto` prefers `live`. Engine
drift is itself a finding — the tests assert both engines agree.

## LIVE result (measured)

TRUE keynote claim **T7-en** ("Japan's GDP reached 4.19 trillion
dollars in 2024"):

- Evidence: 1 URL fetch (`Economy_of_Japan` article, robots-allowed,
  2,013,675 bytes) → quote "From 1995 to 2023, … fell from $5.5
  trillion to $4.2 trillion in nominal terms" → verifier `supported
  [numeric_match]`, 0.24% off, deciding `[m5live-wiki-t7]`
  (`source_year=None`: range quote; M2a skips temporal when unknown).
- Attack (real): counter-query "Japan nominal GDP 2024 IMF World Bank
  trillion dollars" → 1 fetched doc → extract abstained honestly
  (true claim, no contradiction found) → `skeptic.note`, 2 model calls.
- Card (real, model-drafted, `fallback=False`): ES+EN, citations
  `[m5live-wiki-t7]` ⊆ deciding set → `card.published`.
- Cost: **$0.0067** last run ($0.0041 attack + $0.0026 card); 3 live
  runs total ≈ **$0.02**, cap $1.

## Findings / unresolved

1. **WB snapshots cannot support under M2a**: World Bank API quotes
   are bare JSON numbers with no unit word, so the verifier reports
   `unit_mismatch` (units must be known on both sides). The brief's
   preferred path (reuse a real WB snapshot) is unreachable for a
   `supported` verdict until the M2a/M2b unit vocabulary is agreed
   (extends M2B unresolved #1). The live proof uses the brief's
   alternative (fetch 1 URL).
2. **Robots forbids Wikipedia APIs**: `en.wikipedia.org/robots.txt`
   (`User-agent: *`) disallows `/w/` and `/api/` — extracts/REST
   endpoints are off-limits for responsible fetch; article pages are
   explicitly welcome. M2b's `w/api.php` search path uses raw urlopen
   (no robots check) — worth aligning with `fetch.py` policy.
3. **HTML nbsp markup splits figures**: `1.41<span…> </span>billion`
   breaks both verbatim quoting and number parsing; M5 worked around
   it by choosing a contiguously-typed sentence. A robust fix is
   verifier-side (tag-stripped matching) or researcher-side (prefer
   contiguous spans), out of M5 scope.
4. **`source_year=None` skips temporal alignment by contract** ("when
   both are known"). The T7 quote spans 1995–2023 while the claim is
   2024 — numerically decisive (0.24%) but temporally loose. No
   in-snapshot date extraction exists yet (M2A unresolved).
5. Attack retrieval quality bounds attack power: live counter-search
   returned loosely related articles (e.g. China GDP for a Japan
   query); the extract step correctly abstained. Better retrieval
   (M2b grounding reuse) would sharpen the skeptic.
6. Bundle `claims.json` addition (see above) and `verify_bundle.py`
   mirror drift risk: the mirror is pinned to M5 sources; the
   cross-engine test catches drift on the covered paths only.
